Create the bidirectional SyncBridgeManager that syncs all three collections (products, orders, inventory) between Firestore and Ditto. This is the architectural core of the demo app -- it makes the offline-first POS thesis work.

Purpose: Without the bridge, the Ditto local store has no data and the UI has nothing to display. The bridge is the engine that keeps Firestore (cloud truth) and Ditto (local store) in sync, with ChangeGuard preventing infinite write loops.

Output: SyncBridgeManager singleton wired via Koin, started in PosApplication.onCreate(), with unit tests covering all 5 SYNC requirements.

**Step 2: Create `sync/SyncBridgeManager.kt`.**

Package: `live.ditto.pubsec.pos.sync`

Constructor takes `Ditto` and `FirebaseFirestore` (both from Koin).

Key architecture:
- `private val bridgeScope = CoroutineScope(SupervisorJob() + Dispatchers.IO)` -- all bridge work runs here. NEVER use runBlocking inside observer/listener lambdas.
- `private val _isFirebaseConnected = MutableStateFlow(false)` -- exposed as `val isFirebaseConnected: StateFlow<Boolean>`
- `private val listeners = mutableListOf<ListenerRegistration>()` -- Firestore listener handles
- `private val observers = mutableListOf<DittoStoreObserver>()` -- Ditto observer handles
- `private val subscriptions = mutableListOf<Any>()` -- Ditto subscription handles (store as Any since return type may vary)

**`fun start()`:**
1. Call `setupSubscriptions()` -- register 3 Ditto subscriptions via `ditto.sync.registerSubscription("SELECT * FROM ${Collections.PRODUCTS}")` etc. for ORDERS and INVENTORY.
2. Call `ditto.startSync()` -- AFTER subscriptions.
3. Call `setupFirestoreToDittoListeners()` -- 3 SnapshotListeners.
4. Call `setupDittoToFirestoreObservers()` -- 3 Ditto observers.
5. Call `setupConnectionDetection()` -- RTDB .info/connected.

**`setupFirestoreToDittoListeners()` (Firestore -> Ditto direction):**

For each collection (PRODUCTS, ORDERS, INVENTORY), add a Firestore SnapshotListener:
```kotlin
val listener = firestore.collection(collectionName)
    .addSnapshotListener { snapshots, error ->
        if (error != null) {
            Log.e(TAG, "Firestore listener error for $collectionName: ${error.message}")
            return@addSnapshotListener
        }
        if (snapshots == null) return@addSnapshotListener

        for (change in snapshots.documentChanges) {
            val doc = change.document
            // ChangeGuard 1: Skip docs with pending local writes (our Ditto->Firestore bridge wrote them)
            if (doc.metadata.hasPendingWrites) continue
            // ChangeGuard 2: Skip docs already tagged as firestore-sourced
            val syncSource = doc.getString(Collections.Fields.SYNC_SOURCE) ?: ""
            if (syncSource == "firestore") continue

            val data = doc.data.toMutableMap()
            data[Collections.Fields.ID] = doc.id
            data[Collections.Fields.SYNC_SOURCE] = "firestore"
            data[Collections.Fields.LAST_SYNCED_AT] = System.currentTimeMillis()

            bridgeScope.launch {
                try {
                    ditto.store.execute(
                        "INSERT INTO $collectionName DOCUMENTS (:doc) ON ID CONFLICT DO UPDATE_LOCAL_DIFF",
                        mapOf("doc" to data)
                    )
                } catch (e: Exception) {
                    Log.e(TAG, "Firestore->Ditto write failed for $collectionName: ${e.message}")
                }
            }
        }
    }
listeners += listener
```

Extract into a helper: `private fun addFirestoreToDittoListener(collectionName: String)` to avoid repeating the pattern 3 times.

**IMPORTANT for inventory collection:** When bridging Firestore -> Ditto for inventory, do NOT include the `quantity` field in the upsert document. The quantity field is a CRDT counter in Ditto and overwriting it with a plain integer from Firestore would lose concurrent offline decrements. Strip `quantity` from the data map before executing the DQL INSERT for inventory only.

**`setupDittoToFirestoreObservers()` (Ditto -> Firestore direction):**

For each collection, register a Ditto observer:
```kotlin
val observer = ditto.store.registerObserver(
    "SELECT * FROM $collectionName"
) { queryResult ->
    val items = queryResult.use { it.items.map { item -> item.value.toMutableMap() } }
    bridgeScope.launch {
        if (!_isFirebaseConnected.value) return@launch  // SYNC-04: pause when disconnected
        for (doc in items) {
            val syncSource = doc[Collections.Fields.SYNC_SOURCE] as? String ?: ""
            // Only push docs that originated locally (syncSource != "firestore")
            if (syncSource == "firestore") continue

            val id = doc[Collections.Fields.ID] as? String ?: continue
            doc[Collections.Fields.SYNC_SOURCE] = "ditto"
            doc[Collections.Fields.LAST_SYNCED_AT] = System.currentTimeMillis()
            // Remove _id from the payload -- Firestore uses doc path not _id field
            val firestoreData = doc.toMutableMap()
            firestoreData.remove(Collections.Fields.ID)

            try {
                firestore.collection(collectionName)
                    .document(id)
                    .set(firestoreData, com.google.firebase.firestore.SetOptions.merge())
                    .await()
            } catch (e: Exception) {
                Log.e(TAG, "Ditto->Firestore write failed for $collectionName/$id: ${e.message}")
                // Phase 3: log only, no UI error. Auto-retry will happen on next observer fire.
            }
        }
    }
}
observers += observer
```

Extract into helper: `private fun addDittoToFirestoreObserver(collectionName: String)`.

val database = com.google.firebase.Firebase.database
database.getReference("keepAlive").keepSynced(true)
val connectedRef = database.getReference(".info/connected")
connectedRef.addValueEventListener(object : ValueEventListener {
    override fun onDataChange(snapshot: DataSnapshot) {
        val connected = snapshot.getValue(Boolean::class.java) ?: false
        _isFirebaseConnected.value = connected
        if (connected) {
            Log.i(TAG, "Firebase connected — bridge active")

        }
    }

    }
})
