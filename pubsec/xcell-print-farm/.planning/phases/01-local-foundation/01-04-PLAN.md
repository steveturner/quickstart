  <action>
Create a multi-stage Dockerfile:

```dockerfile
# Dockerfile
# Build stage
FROM node:20-alpine AS builder
WORKDIR /app

# Copy package files
COPY package*.json ./

# Install dependencies
RUN npm ci

# Copy source
COPY . .

# Build arguments for Ditto config (passed at build time)
ARG DITTO_APP_ID
ARG DITTO_PLAYGROUND_TOKEN
ARG DITTO_AUTH_URL
ARG DITTO_WEBSOCKET_URL

# Create env file for build
RUN echo "DITTO_APP_ID=${DITTO_APP_ID}" > .env.local && \
    echo "DITTO_PLAYGROUND_TOKEN=${DITTO_PLAYGROUND_TOKEN}" >> .env.local && \
    echo "DITTO_AUTH_URL=${DITTO_AUTH_URL}" >> .env.local && \
    echo "DITTO_WEBSOCKET_URL=${DITTO_WEBSOCKET_URL}" >> .env.local

# Build the app
RUN npm run build

# Production stage
FROM nginx:alpine
WORKDIR /usr/share/nginx/html

# Copy built assets
COPY --from=builder /app/dist .

# Copy nginx config
COPY nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

Create nginx.conf for SPA routing:

```nginx
# nginx.conf
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    # SPA routing - serve index.html for all routes
    location / {
        try_files $uri $uri/ /index.html;
    }

    # Cache static assets
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }

    # Gzip compression
    gzip on;
    gzip_types text/plain text/css application/json application/javascript text/xml application/xml;
}
```

<task type="auto">
  <name>Task 2: Create docker-compose.yml</name>
  <files>docker-compose.yml</files>
  <action>
Create docker-compose.yml:

```yaml
# docker-compose.yml
services:
  xcell-dashboard:
    build:
      context: .
      dockerfile: Dockerfile
      args:
        DITTO_APP_ID: ${DITTO_APP_ID}
        DITTO_PLAYGROUND_TOKEN: ${DITTO_PLAYGROUND_TOKEN}
        DITTO_AUTH_URL: ${DITTO_AUTH_URL}
        DITTO_WEBSOCKET_URL: ${DITTO_WEBSOCKET_URL}
    ports:
      - "8080:80"
    restart: unless-stopped
```

Note: Environment variables are passed as build args and baked into the static build.
The .env.local file in the project root provides these values.
